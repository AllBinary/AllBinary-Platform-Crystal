                             AllBinary Platform Crystal

What is it?

This repository contains code generated by the AllBinary Platform for support in Crystal.  
This repo is used to allow developers to skip the Crystal code generation step.

What are some example games with this Crystal code?

https://allbinary.itch.io (The downloads with "-crystal" in the filename are Crystal only builds. Currently that only includes nothing. Also the Crystal builds are not available on Google Play or other stores.)
